# Training a Custom Dagbani Byte-Level BPE Tokenizer

This example demonstrates how to train, evaluate, and export a custom Byte-Level BPE tokenizer tailored for Dagbani using `train_dagbani_tokenizer.py`.

---

## 1. Prepare Corpus File

Ensure you have a cleaned Dagbani text file (e.g., `cleaned_corpus.txt` generated by `dataset_cleaner.py`):

```bash
# Preview first few lines of corpus
head -n 5 data/cleaned_corpus.txt
```

---

## 2. Train Tokenizer via CLI

Train an 8,000 vocabulary tokenizer preserving Dagbani digraphs (`kp`, `gb`, `ŋm`, `ny`, `ch`, `sh`) and BGL glyphs:

```bash
python ../scripts/train_dagbani_tokenizer.py \
    --corpus-file data/cleaned_corpus.txt \
    --vocab-size 8000 \
    --output-dir tokenizers/dagbani_bpe_8k/ \
    --preserve-digraphs \
    --min-frequency 2
```

Expected Output Files in `tokenizers/dagbani_bpe_8k/`:
- `tokenizer.json` (Full serialized tokenizer configuration)
- `vocab.json` (Token to index mapping)
- `merges.txt` (BPE merge rules)
- `tokenizer_config.json` (HuggingFace compatibility config)

---

## 3. Evaluate Subword Fertility in Python

Verify subword fertility using the Python API:

```python
from tokenizers import Tokenizer

tokenizer = Tokenizer.from_file("tokenizers/dagbani_bpe_8k/tokenizer.json")

test_sentences = [
    "O biɛla Yendi zúŋɔ ka nyɛ pukpara ŋun kpaŋsiri kpaŋkpaŋ koobu.",
    "Dagbaŋ kaya ni ta'ada nyɛla din mali yaa pam.",
    "Wabgu maa mini gballi maa viɛla pam."
]

total_words = 0
total_tokens = 0

for sent in test_sentences:
    words = sent.split()
    enc = tokenizer.encode(sent)
    tokens = enc.tokens
    print(f"Sentence: {sent}")
    print(f"Tokens:   {tokens}")
    print(f"Word count: {len(words)}, Token count: {len(tokens)}")
    print("-" * 40)
    total_words += len(words)
    total_tokens += len(tokens)

fertility = total_tokens / float(total_words)
print(f"Average Dagbani Subword Fertility: {fertility:.2f} tokens/word")
# Target: < 1.35 tokens/word
```

---

## 4. Integration with Hugging Face `transformers`

Load your trained tokenizer directly with Hugging Face PreTrainedTokenizerFast:

```python
from transformers import PreTrainedTokenizerFast

tokenizer = PreTrainedTokenizerFast(
    tokenizer_file="tokenizers/dagbani_bpe_8k/tokenizer.json",
    bos_token="<s>",
    eos_token="</s>",
    unk_token="<unk>",
    pad_token="<pad>"
)

text = "A nyɛla Dagbanli sɔŋda."
input_ids = tokenizer.encode(text)
decoded = tokenizer.decode(input_ids)
print("Decoded text:", decoded)
```
