## 3. ATR Harmony Mechanics & Propagation Constraints

1. **Harmonic Sets**:
   - **[+ATR] Group**: `{ /i/, /iː/, /e/, /eː/, /o/, /oː/, /u/, /uː/, [a̘] }`
   - **[-ATR] Group**: `{ /ɨ/, /ɛ/, /ɛː/, /ɔ/, /ɔː/, [ʊ], /a/, /aː/ }`

2. **Suffix-to-Root Regressive Harmony**:
   - A [+ATR] suffix (`-o`, `-e`) raises an underlying [-ATR] root vowel to [+ATR]:
     $$\text{Root } /\text{dɔr}/ + \text{Suffix } /\text{-o}/ \longrightarrow \mathbf{[dóró]} \quad (\text{'illness' - singular})$$
     $$\text{Root } /\text{dɔr}/ + \text{Suffix } /\text{-tɨ}/ \longrightarrow \mathbf{[dɔ́rtɨ́]} \quad (\text{'illnesses' - plural})$$

3. **Root-to-Suffix Progressive Harmony**:
   - A [+ATR] root vowel (`/i/`, `/u/`) spreads [+ATR] rightward into inflectional suffixes:
     $$\text{Root } /\text{dir}/ + \text{Suffix } /\text{-gʊ}/ \longrightarrow \mathbf{[dirigu]} \quad (\text{'utensil/tool'})$$

4. **Opaque Consonant Blocker Constraint**:
   - The alveolar coronal consonants **`{ /l/, /s/, /r/ }`** act as opaque barriers that strictly block progressive root-to-suffix [+ATR] spread from a root `/i/`:
     $$\text{Root } /\text{pil}/ + \text{Suffix } /\text{-i}/ \longrightarrow \mathbf{[pílɨ́]} \quad (\text{\emph{never} } *[pili])$$
     $$\text{Root } /\text{jin}/ + \text{Suffix } /\text{-si}/ \longrightarrow \mathbf{[jínsɨ́]} \quad (\text{\emph{never} } *[jinsi])$$

5. **Syntactic and Compound Domain Constraint**:
   - ATR vowel harmony is strictly confined to the morphological word (root + affixes).
   - Harmony **never propagates across word or compound boundaries**:
     $$\text{Compound: } [\text{bí}]_{\text{root}} + [\text{bɛ́ʔʊ́}]_{\text{root}} \longrightarrow \mathbf{[bí\ bɛ́ʔʊ́]} \quad (\text{'ugly child', \emph{never} } *[bí\ béʔú])$$

## 4. Register Tone System & Pitch Terracing

Dagbani is a **register tone language** with **two level tones**, an automatic downstep system, and moraic tone-bearing codas.

### 4.1 Pitch Levels & Diacritics
- **High Tone (H)**: Marked with acute accent (`´`): e.g. *bá* ('father').
- **Low Tone (L)**: Marked with grave accent (`` ` ``): e.g. *tìa* ('tree').
- **Downstep (!H)**: Lowers the ceiling of succeeding High tones following an underlying or overt Low tone:
  $$H_1 - L_1 - H_2 \implies F_0(H_2) < F_0(H_1)$$
- **Contour Tones**: Surface as combinations of level tones over bimoraic syllables (Falling `HL` $\hat{a}$, Rising `LH` $\check{a}$).

### 4.2 Tone-Bearing Units (TBUs)
1. **Vocalic Moras**:
   - Short vowel ($V$) = 1 TBU.
   - Long vowel ($VV$) = 2 TBUs.
   - Diphthong ($V_1V_2$) = 2 TBUs.
2. **Moraic Coda Nasals**:
   - Syllable-final nasals (`/m, n, ŋ/`) in coda position bear an independent tone:
     - *sɔ́ŋ* [sɔ́ŋ́] ('grass mat') $\rightarrow$ H-H melody over 2 TBUs (vowel + coda nasal).
     - *m̀-bɔ́* [m̀-bɔ́] ('I want') $\rightarrow$ L syllabic nasal prefix + H verbal root.
